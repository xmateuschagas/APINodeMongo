# APINodeMongo

Esta é uma API RESTful para gerenciamento de contas e tarefas, construída com Node.js e MongoDB. A API é segura e todas as rotas são protegidas por autenticação via JWT (JSON Web Tokens).

## 💻 Tecnologias

-   **Node.js** & **Express**: Ambiente de execução e framework do servidor.
-   **MongoDB** & **Mongoose**: Banco de dados e ODM para modelagem de dados.
-   **Zod**: Biblioteca para validação de dados de entrada.
-   **JWT** & **bcryptjs**: Para autenticação segura e criptografia de senhas.

### 1. Pré-requisitos
Certifique-se de ter o [Node.js](https://nodejs.org/) e o [MongoDB Atlas](https://www.mongodb.com/cloud/atlas) configurados.
